    Validation: raw vs cleaned

    Cleaning rules

    • Null subject mark → replaced with the student's mean of their other valid subjects.
    • 0 subject mark → treated as invalid (absent or entry error) and filled the same way.
    • Null or 0 attendance → replaced with the class median attendance.
    • Duplicates → exact duplicate rows and repeated names are removed (none found).
    • Outliers → flagged with the 1.5 × IQR rule. Genuine scores are kept.
